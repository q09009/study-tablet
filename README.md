# Study Tablet

강의 들을 때 태블릿에서 쓰는 안드로이드 공부 앱 (Kotlin + Jetpack Compose).

## 기능

VS Code 같은 레이아웃: 왼쪽 액티비티 바(탐색기·AI 질문·녹음·설정) + 파일 트리, 오른쪽 편집 영역(PDF·문서·녹음·AI 질문이 각각 별도 창, 최대 4개).

- **작업 폴더 / 파일 트리** – 기기의 폴더 하나를 골라(SAF) 그 안의 PDF·메모·요약·녹음을 트리로 관리. 새 메모, 새 폴더, PDF 가져오기, 이름 변경, 이동, 삭제(항목 길게 누르기). 길게 누른 채로 끌어서 폴더에 놓으면 이동(빈 곳에 놓으면 작업 폴더 최상위로; 목록 끝으로 끌면 자동 스크롤, 접힌 폴더 위에 잠시 머물면 펼쳐짐), "이동…" 메뉴로 폴더를 골라 옮길 수도 있습니다. PDF를 옮기면 `요약.md`도 함께 옮겨집니다.
- **종류별 창** – PDF, 마크다운(요약·노트·전사), 녹음/오디오, AI 질문은 각자 자기 창(PDF → 문서 → 녹음 → AI 질문 순)에 탭으로 열립니다. 파일을 길게 눌러 "옆에 열기"하면 같은 종류의 창을 하나 더 만들어 비교할 수 있고, 탭을 길게 눌러 옆 창으로 옮기거나 새 창으로 분리합니다. 창 사이 구분선을 드래그해 크기 조절(저장됨). 열린 탭은 다시 실행해도 유지됩니다.
- **ChatGPT 로그인 (Codex OAuth)** – Codex CLI와 같은 "Sign in with ChatGPT" 흐름. ChatGPT 구독의 Codex 사용량으로 AI 기능을 쓰고, 설정에서 사용량(5시간/주간 한도)을 표시합니다.
- **AI 모델 드롭다운** – 로그인하면 사용 가능한 모델 목록을 불러와 드롭다운에서 선택(직접 입력도 가능).
- **PDF 뷰어** – 50%~500% 확대/축소(핀치, 더블탭, +/− 버튼, 맞춤).
- **AI 요약** – PDF 탭의 "AI 요약"으로 마크다운 요약을 생성해 PDF 옆에 `<이름> 요약.md`로 저장하고 문서 창에 엽니다. 이미 있으면 바로 열고, 메뉴에서 다시 만들 수 있습니다.
- **메모** – 마크다운(.md) 메모. 미리보기/편집 전환, 자동 저장.
- **AI 질문 창** – 액티비티 바의 말풍선을 누르면 'AI 질문' 창이 오른쪽에 열립니다. 구분선을 드래그해 폭을 조절하고, 보고 있는 문서를 맥락으로 개념을 바로 물어볼 수 있습니다.
- **테마** – 설정 > 화면에서 시스템/라이트/다크 선택.
- **녹음** – 마이크 버튼으로 녹음 탭을 열어 녹음(화면을 꺼도 계속). 탐색기에서 선택한 폴더(없으면 작업 폴더)에 `.m4a`로 저장되고, 트리에서 눌러 재생/탐색/배속. **실시간 전사**(Android 13+)를 켜 두면 녹음하면서 받아 적어 화면에 보여 주고(언어: 한국어 / English / 한국어 + English — 마지막은 Android 14+에서 문장마다 언어를 자동 감지), 끝나면 `녹음 … 전사.md`(문장별 `[mm:ss]` 시간 표시)로 함께 저장합니다. 기기 내(온디바이스) 음성 인식을 우선 쓰며, 필요한 언어의 음성 모델이 없으면 다운로드를 안내하고 그동안은 Google 기본 음성 인식을 사용합니다.
- **Nextcloud** – 액티비티 바의 구름 아이콘 → 서버 주소 입력 → 브라우저에서 로그인 승인(Login Flow v2, 앱 비밀번호 발급). 서버 폴더를 탐색하고 파일을 누르면 탐색기에서 선택한 폴더로 받아 바로 엽니다. 폴더를 길게 누르면 하위 폴더까지 통째로 받기. 이미 받은 파일(같은 이름·크기)은 체크 표시되고 건너뜁니다. ????? ?????? ?? ?? **Nextcloud? ???**? ??? ?? ?? - **AI 과목 정리** – 작업 폴더 바로 아래에 있는 PDF를 AI가 읽고 과목을 분류(기존 폴더 우선, 필요하면 새 과목). 확인 창에서 과목을 고치거나 체크를 해제한 뒤 "이동"을 눌러야 실제로 옮겨지며, 같은 이름의 `요약.md`도 함께 이동합니다. 탐색기 상단 배너나 ⋮ 메뉴 "AI로 과목 정리".
- 좁은 화면에서는 사이드바가 편집 영역 위에 겹쳐 뜨고 창은 하나만 보이며, 탭 줄 오른쪽 버튼으로 창을 전환합니다.
## 빌드 & 설치

```powershell
.\gradlew.bat assembleDebug
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

요구사항: JDK 17+, Android SDK 36 (`local.properties`의 `sdk.dir`).

## 릴리스 & 앱 내 업데이트

- 릴리스: `git tag v0.2.0; git push origin v0.2.0` → GitHub Actions(`.github/workflows/release.yml`)가 서명된 APK를 빌드해 GitHub Release에 올립니다. 태그가 버전이 됩니다(`vX.Y.Z` → versionCode `X*10000+Y*100+Z`).
- 앱은 실행 시 공개 저장소의 최신 릴리스를 확인하고, 설정의 "앱 업데이트" 카드에서 버튼 한 번으로 다운로드·설치합니다(토큰 불필요).
- 서명 키: `keystore.properties`(gitignore됨) + 키스토어 파일. CI는 `RELEASE_KEYSTORE_BASE64`, `RELEASE_KEYSTORE_PASSWORD` 시크릿을 씁니다. **키스토어를 잃어버리면 기존 설치본에 업데이트할 수 없으니 백업 필수.**
- 디버그 빌드가 설치되어 있으면 서명이 달라 업데이트가 안 됩니다. 처음 한 번은 앱을 지우고 릴리스 APK를 설치하세요.
- 로컬 릴리스 빌드: `.\gradlew.bat assembleRelease "-PappVersion=0.2.0"`

## 참고 / 주의

- 로그인은 기기 안에서 `http://localhost:1455/auth/callback` 로컬 서버로 콜백을 받습니다(Codex CLI와 동일 포트). 로그인 완료 후 브라우저 페이지의 "앱으로 돌아가기"를 누르세요.
- Codex CLI의 공개 OAuth 클라이언트와 ChatGPT Codex 백엔드(`chatgpt.com/backend-api/codex`)를 사용하는 비공식 방식이라 OpenAI 측 변경으로 동작이 바뀔 수 있습니다.
- 모델이 거부되면 설정의 모델 드롭다운에서 다른 모델을 고르세요.
- 스캔본(이미지) PDF는 텍스트가 없어 요약할 수 없습니다.
- 토큰은 앱 전용 저장소에 보관됩니다.
- Nextcloud 앱 비밀번호도 앱 전용 저장소에 보관되며, 로그아웃하면 서버에서 폐기됩니다. LAN의 `http://` 서버도 쓸 수 있습니다.
